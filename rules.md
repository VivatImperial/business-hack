Правила

Директории
- ai-agent это директория для сервиса с аи-агентом
- backend это директория для api

Общие правила:
Все запросы и ответы возвращаются в виде Pyndatic-моделей, которые лежат в shemas
Работа с БД осуществляется через SQLAlchemy 2.0, поля ORM моделей прописываются через Mapped[]
Модели режат в db/models
Репозитории отвечают за получение данных из БД; они лежат в db/repositories
Бизнес логика должна быть вынесена в сервисный слой services/
Роутеры лежат в routers; роутеры для админки лежат в routers/admin; роутеры апишки лежат в routers/internal
В качестве фремйворка используется FastAPI
Код должен быть асинхронным
Вебсервер uvicorn

Код-стайл:
В коде должны быть прописаны аннотации типов
Комментарии не приветствуются; если есть необходимость добавлять информацию к коду, то только docstrings
Нейминг должен быть понятным, но не перегруженным - старайся задавать публичные неймы для интерфейса 8-15 символов
Код должен соответствовать single-responsibility; использую инверсию зависимостей, там где уместно

Инфраструктура:
Все сервисы должны быть прописаны в docker-compose и запускаться одной командой docker compose up
